# Kora Estudio

## Descripción del proyecto

Kora Estudio es un sitio web para un estudio especializado en arquitectura interior, remodelación residencial y manejo de espacios.

El proyecto busca presentar los servicios del estudio, mostrar sus proyectos arquitectónicos y facilitar el contacto con potenciales clientes.

## Objetivo

Desarrollar una página web responsive tomando como referencia un diseño visual proporcionado para una prueba evaluativa de RIWI.

## Tecnologías utilizadas

- HTML5: estructura y contenido del sitio.
- CSS3: estilos, distribución y diseño responsive.
- Google Fonts: tipografías Fraunces y Plus Jakarta Sans.
- Google Material Symbols: iconografía.
- Unsplash: recursos fotográficos.

## Estructura del proyecto

```text
kora-estudio/
├── index.html
├── README.md
├── css/
│   └── styles.css
└── img/
```

## Características

- Diseño adaptable a escritorio y dispositivos móviles.
- Navegación entre las diferentes secciones.
- Presentación de servicios y proyectos.
- Sección de testimonios.
- Formulario de contacto.

## Restricciones

El desarrollo se realizará únicamente con HTML5 y CSS3, sin JavaScript ni pseudo-selectores, siguiendo las indicaciones de la prueba.

## Autor

Proyecto académico desarrollado como parte del proceso de formación en RIWI.

## Bitácora de desarrollo

### Etapa 1 - Preparación del proyecto
- Creación de la estructura de carpetas.
- Creación de index.html.
- Creación de css/styles.css.
- Creación del README.
- Inicialización del repositorio Git.
- Configuración de identidad de GitHub.
- Publicación del proyecto en GitHub.

### Etapa 2 - Estructura HTML y navegación
- Configuración del documento HTML5.
- Configuración del idioma español.
- Configuración de metadatos y viewport.
- Integración de Google Fonts.
- Integración de Google Material Symbols.
- Creación del encabezado semántico.
- Creación del menú de navegación.
- Creación de la estructura principal.
- Definición de variables CSS.
- Implementación de Flexbox.
- Primera adaptación responsive mediante media queries.
- Navegación horizontal en escritorio y vertical en móvil.

### Etapa 3 - Hero principal

- Reemplazo del contenido temporal de bienvenida.
- Creación de la sección Hero.
- Implementación de títulos y descripción.
- Integración de fotografía de Unsplash.
- Implementación de degradado con linear-gradient().
- Creación del botón principal.
- Aplicación de background-size: cover.
- Aplicación de background-position: center.
- Adaptación responsive del Hero.
